# Tabla Viva

Tap an element. See what it is, when it melts, how its electrons sit, and what Wikipedia says about it.

Spanish opens first. EN switches the interface. The long paragraphs follow that language when a Spanish extract exists.

## Try it

```bash
npm install
npm test
npm run dev
```

Open http://localhost:5174 . On a phone, slide the table sideways.

The public site is https://vdm285.github.io/interactive-science/ once Pages has published `main`.

## What is real

All 118 elements. Masses, melt and boil temperatures, density, electron shells and configurations come from the public [Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON) compilation. The temperature slider turns those temperatures into solid, liquid or gas. It does not invent a phase.

Spanish names are the ones used in Mexican classrooms. Search also finds wolframio, circonio, criptón and cinc.

The atom is a Bohr model and the screen says so. Shells are the shell counts from the data. If an outer shell starts early, the ring is dashed.

Wikipedia paragraphs are CC BY-SA. The card links the article.
